# Plan del proyecto - Página Web del Clima

## Objetivo
Crear una página web que permita seleccionar un país y consultar
información del clima utilizando una API.

## Tecnologías
- HTML
- CSS
- JavaScript
- API del clima

## Funcionalidades

1. Mostrar una barra de navegación.
2. Mostrar un selector de país.
3. Permitir seleccionar una ciudad.
4. Mostrar información del clima.
5. Mostrar temperatura.
6. Mostrar condiciones climáticas.
7. Mostrar humedad.
8. Mostrar velocidad del viento.
9. Mostrar un mensaje mientras se consulta la API.
10. Mostrar un mensaje de error si no se encuentra información.

## Etapas

### Etapa 1 - Diseño
- Crear la estructura HTML.
- Crear la barra superior.
- Crear el selector de país.
- Crear el área donde aparecerá el clima.

### Etapa 2 - Estilos
- Diseñar la página con CSS.
- Hacerla responsive.
- Crear tarjetas para la información del clima.

### Etapa 3 - JavaScript
- Detectar el país seleccionado.
- Preparar las funciones para consultar la API.
- Procesar la respuesta.
- Mostrar los datos en la página.

### Etapa 4 - API
- Agregar la API proporcionada.
- Configurar la URL.
- Enviar la ubicación seleccionada.
- Mostrar los datos recibidos.

### Etapa 5 - Pruebas
- Probar diferentes países.
- Comprobar errores.
- Comprobar que los datos se muestran correctamente.
- Comprobar la página en computadora y celular.

# AGENTS.md

## Descripción del proyecto

Este proyecto consiste en una página web para consultar información
del clima utilizando una API.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- API REST

## Reglas

- Mantener separado HTML, CSS y JavaScript.
- No colocar CSS directamente dentro del HTML.
- No colocar JavaScript directamente dentro del HTML.
- Utilizar nombres de variables claros.
- Mantener el código sencillo y fácil de entender.
- Utilizar funciones para separar las diferentes tareas.
- No modificar archivos que no sean necesarios.
- No eliminar funcionalidades existentes sin autorización.

## JavaScript

La lógica relacionada con la API debe permanecer en:

js/app.js

La información obtenida de la API debe mostrarse dinámicamente
en la página.

## Diseño

El diseño debe ser limpio, moderno y sencillo.

La página debe funcionar correctamente en computadora y dispositivos
móviles.

## API

La API será agregada posteriormente.

Mientras no esté disponible, se pueden utilizar datos de prueba
para comprobar el funcionamiento de la interfaz.

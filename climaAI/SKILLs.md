# SKILLs

## HTML

Debe ser capaz de:

- Crear estructuras HTML5.
- Utilizar etiquetas semánticas.
- Crear formularios y selectores.
- Organizar correctamente el contenido.

## CSS

Debe ser capaz de:

- Crear diseños responsive.
- Utilizar Flexbox.
- Utilizar Grid cuando sea necesario.
- Crear tarjetas.
- Crear botones.
- Utilizar media queries.
- Crear animaciones sencillas.

## JavaScript

Debe ser capaz de:

- Manipular el DOM.
- Utilizar eventos.
- Trabajar con funciones.
- Utilizar fetch().
- Trabajar con JSON.
- Manejar errores.
- Actualizar información dinámicamente.

## API

Debe ser capaz de:

- Realizar solicitudes HTTP.
- Construir URLs utilizando los datos seleccionados.
- Procesar respuestas JSON.
- Mostrar los datos recibidos.
- Manejar errores de conexión.

## Buenas prácticas

- Código organizado.
- Variables con nombres descriptivos.
- Funciones pequeñas.
- Comentarios únicamente cuando sean necesarios.
- Evitar código repetido.
